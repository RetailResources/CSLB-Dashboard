# CSLB Dashboard

Static Excel-backed sales dashboard for GitHub Pages.

## Files
- `index.html`
- `styles.css`
- `app.js`
- `sales-dashboard.xlsx`

## How it works
The dashboard uses SheetJS in the browser to load `sales-dashboard.xlsx` from the repository and renders:
- Region summary
- District ranking
- District drilldown
- Region outliers view

## Deployment
Host the repo on GitHub Pages and keep `sales-dashboard.xlsx` in the repository root.
